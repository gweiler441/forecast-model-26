## OUTCOME: 
Two-party vote totals measured in first round of voting (if state has a ranked-choice system). Measured as normalized margin, D positive and R negative
Margin = (D-R)/(D+R)

## FREEZE DATE: 
Nothing changed after October 31st

## CONVERSION RULES: 
First-choice results always used for consistency. Drop undecideds and normalize margins with two-party totals. Priority order for poll type: 1) LV, 2) RV, 3) A
